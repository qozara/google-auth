# `@qozara/google-auth`

Isomorphic, device-local Google OAuth2 session store with expiry validation, incremental scope tracking (`openid email profile` vs `drive.file` + `drive.appdata`), legacy credential migration, and optional React 18/19 hooks (`@qozara/google-auth/react`).

See the [repository README](https://github.com/qozara/google-auth#readme) for full documentation.
